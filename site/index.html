What is Hand of GOD?

Hand of GOD is a short, hand-drawn pixel game about a celestial hand with a lot of build-up and very little patience. It opens with a proper start menu, spends exactly as long loading as it says it will, and then delivers a cinematic, particle-soaked moment that has been politely described as “a comedy”.

Everything in it — the pixel art, the chiptune music, the installer icon — is generated from code, so the whole game is a couple of hundred kilobytes of stubbornness wrapped in a normal Windows installer. It runs offline, it collects nothing, and it fits in a single sitting.

Features

  • One hand, drawn by hand

    Not a stock photo, not an asset pack — a pixel hand built from rounded shapes and shading maths, one pixel at a time.

  • A load screen you can trust

    It says twenty seconds. It means twenty seconds. No fake progress bars.

  • Cinematic build-up

    Music, light, particles and an amount of anticipation that many longer games would consider excessive.

  • A real Windows installer

    Pick your own install folder, get a desktop shortcut, and a normal uninstaller that actually removes things.

  • Volume-only settings

    Genuinely just volume control. No upselling you a brightness slider.

  • Free and offline

    No ads, no accounts, no telemetry, no internet connection required after download.

How to install Hand of GOD on Windows

  1. Download the installer

    Grab HandOfGOD-Setup-1.0.0.exe from the download button or from the GitHub releases page.

  2. Run it and choose a folder

    The setup asks where you want the game installed. Any folder will do.

  3. If SmartScreen complains

    Small unsigned indie installers trigger a warning. Choose More info → Run anyway.

  4. Launch from the Start Menu

    A desktop shortcut and a Start Menu entry called Hand of GOD appear when it finishes.

Frequently asked questions

Is Hand of GOD really free?

Yes. It is free to download and play. No ads, no accounts, no microtransactions, and nothing to buy afterwards.

Does it work on Windows 10 and Windows 11?

It is built for 64-bit Windows 10 and Windows 11. The installer lets you pick the folder it installs into and creates desktop and Start Menu shortcuts.

How long is the game?

About forty-five seconds, including a deliberately long load screen. It has a beginning, a middle and a very definite end.

Does it need an internet connection?

No. Once the installer is downloaded you can play entirely offline. The game collects no data and sends nothing anywhere.

Why does SmartScreen warn me about the installer?

The installer is not code-signed, so Windows shows a warning for small indie releases. Choose More info, then Run anyway.
